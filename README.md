# Φιλοσοφία

A small, hopefully fun **philosophy quiz** covering questions about philosophers, philosophical ideas, and the history of philosophy.

## 🔗 Play

**[Play Philosophy Quiz](https://byc0jl3.neocities.org/philosophy-quiz/)**

## 🌙 Theme

The quiz automatically follows the user's system preference for light or dark mode using CSS `prefers-color-scheme`.

## ✨ Features

* 🧠 Philosophy-focused quiz questions
* 📝 Multiple-choice questions
* 🎯 Score tracking
* 🏆 High-score table
* 🌙 Automatic light/dark theme support
* 📱 Responsive design
* 🔀 Questions stored separately in JSON
* ⚡ No frameworks or external dependencies

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**
* **JSON**

## 💭 About

This project started as a small experiment combining two things I enjoy: **philosophy and web development**.

The goal was to create a simple quiz experience while experimenting with JavaScript, structured question data, responsive design, themes, scoring, and persistent high scores.
